# Multimodal File Ingestion and Retrieval Design Bundle

This package contains an interview-ready design artifact for **Design multimodal file ingestion and retrieval**.

## Files

- `multimodal-file-ingestion-retrieval.mdx` — main MDX guide.
- `architecture.svg` — high-level architecture diagram used by the MDX.
- `ux-mock.svg` — frontend UX mock used by the MDX.
- `multimodal-ingestion-retrieval.excalidraw` — editable Excalidraw source.

## How to view

1. Open the `.mdx` file in a Docusaurus, Next.js MDX, or GitHub-compatible viewer.
2. Open the `.svg` files directly in any browser.
3. Open the `.excalidraw` file at https://excalidraw.com by importing the file.

## Interview emphasis

Highlight:

- Functional and non-functional requirements.
- Dropbox-like storage foundation.
- AI-native ingestion pipeline.
- Structure-aware chunking.
- Hybrid keyword + vector retrieval.
- Permission-safe retrieval.
- Citation quality.
- Idempotent processing.
- Deletion consistency.
- Golden-set retrieval tests.
