# React Interview Components

Simple React component implementations for 45-60 minute interview coding rounds.

Each folder contains:

- one component file (`*.jsx`)
- one CSS file (`*.css`)

## Components included

1. Autocomplete / typeahead
2. Searchable dropdown with keyboard navigation
3. Multi-select filter
4. Date range picker
5. Calendar availability picker
6. Image carousel
7. Infinite scroll listing
8. Virtualized list/grid
9. Modal/dialog with focus trapping
10. Toast notification system
11. Accordion / disclosure
12. Tabs with ARIA
13. Tooltip / popover positioning
14. Filter sidebar
15. Pagination
16. Reservation form with validation
17. Guest counter with min/max rules
18. Price breakdown
19. Map + listing synchronization UI
20. Responsive photo grid
