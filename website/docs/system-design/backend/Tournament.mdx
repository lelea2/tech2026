# Tourney Copilot: Staff-Level End-to-End System Design

## Goal

Build **Tourney Copilot**, an AI-assisted tournament operations platform that helps club operators create, manage, schedule, and optimize pickleball round-robin tournaments.

The system should allow operators to:

- Create tournaments
- Manage player rosters
- Generate round-robin schedules
- Detect operational issues automatically
- Receive AI-powered recommendations
- Handle player dropouts and schedule changes safely

---

# 2. Architecture Philosophy

This is primarily an **operational workflow system**, not an AI product.

AI should help operators make decisions, but AI should never become the source of truth.

Core principles:

```text
Database = Source of Truth
Backend Services = Business Logic
AI = Advisor
Frontend = Workflow Layer
```

The system must guarantee:

- No duplicate players
- No duplicate matches
- No court conflicts
- No player double-booking
- Safe handling of player dropouts
- Auditable schedule changes

# 5. Why SQL Instead of Document Database

## SQL Strengths

Tournament systems are highly relational.

```text
Event
 ├── Players
 ├── Courts
 ├── Rounds
 └── Matches
       ├── Players
       └── Scores
```

Common queries:

- Find all matches for a player
- Detect duplicate matchups
- Count player byes
- Identify court utilization
- Analyze fairness metrics

SQL excels at these operations.

---

## Transaction Safety

Schedule generation requires atomicity.

```text
Create Rounds
Create Matches
Assign Courts
Assign Players
Generate Warnings
```

Either all succeed or all fail.

```sql
BEGIN;
...
COMMIT;
```

Document databases generally require additional complexity for this level of consistency.

---

## Future Analytics

The product will eventually need:

```text
Player participation trends
Court utilization
Win rates
Fairness metrics
Tournament statistics
```

SQL is significantly better suited for analytical workloads.

---

## Recommended Hybrid Approach

Use relational tables for operational data.

Use JSONB for flexible AI metadata.

```sql
warnings.context JSONB
copilot_messages.tool_result JSONB
events.metadata JSONB
```

This provides both structure and flexibility.

# 8. Round-Robin Scheduling Algorithm

## Circle Method

When player count is odd:

```text
Add BYE placeholder
```

Example:

```text
P1
P2
P3
P4
P5
BYE
```

For each round:

```text
Pair first half with second half
Rotate players
Assign courts
Repeat
```

Complexity:

```text
O(n²)
```

which is acceptable for club-sized tournaments.

# 9. Warning Engine

Warnings should be rule-based.

```ts
type WarningRule = {
  type: string;
  severity: 'info' | 'warning' | 'critical';
  evaluate(state: TournamentState): Warning[];
};
```

Example rules:

```text
OddPlayerCountRule
TooFewCourtsRule
DuplicateMatchupRule
CourtConflictRule
PlayerDoubleBookedRule
ByeBalanceRule
DropoutImpactRule
```

Benefits:

- Deterministic
- Explainable
- Testable
- Reliable

### React round-robin example

```js
import { useMemo, useState } from "react";
import styles from "./styles.module.css";

type Player = {
  id: string;
  name: string;
};

type EventSettings = {
  name: string;
  courts: number;
  gamesPerMatch: number;
};

type Match = {
  id: string;
  round: number;
  court: number;
  playerA: Player | null;
  playerB: Player | null;
};

const uid = () => crypto.randomUUID();

function generateRoundRobin(players: Player[], courts: number): Match[] {
  if (players.length < 2) return [];

  const list: Array<Player | null> =
    players.length % 2 === 0 ? [...players] : [...players, null];

  const rounds = list.length - 1;
  const matchesPerRound = list.length / 2;
  const schedule: Match[] = [];

  let rotating = [...list];

  for (let round = 1; round <= rounds; round++) {
    for (let i = 0; i < matchesPerRound; i++) {
      const playerA = rotating[i];
      const playerB = rotating[rotating.length - 1 - i];

      schedule.push({
        id: `${round}-${i}`,
        round,
        court: (i % Math.max(courts, 1)) + 1,
        playerA,
        playerB,
      });
    }

    rotating = [
      rotating[0],
      rotating[rotating.length - 1],
      ...rotating.slice(1, rotating.length - 1),
    ];
  }

  return schedule;
}

function getWarnings(
  players: Player[],
  settings: EventSettings,
  schedule: Match[]
): string[] {
  const warnings: string[] = [];

  if (!settings.name.trim()) {
    warnings.push("Event name is missing.");
  }

  if (players.length < 4) {
    warnings.push("Round robin works better with at least 4 players.");
  }

  if (players.length % 2 !== 0) {
    warnings.push("Uneven player count: one player will receive a bye each round.");
  }

  const maxMatchesPerRound = Math.ceil(players.length / 2);

  if (settings.courts < maxMatchesPerRound) {
    warnings.push(
      `Too few courts: ${maxMatchesPerRound} matches may be needed per round, but only ${settings.courts} court(s) available.`
    );
  }

  const pairSet = new Set<string>();

  for (const match of schedule) {
    if (!match.playerA || !match.playerB) continue;

    const pair = [match.playerA.id, match.playerB.id].sort().join("-");
    if (pairSet.has(pair)) {
      warnings.push(
        `Duplicate matchup detected: ${match.playerA.name} vs ${match.playerB.name}.`
      );
    }

    pairSet.add(pair);
  }

  return [...new Set(warnings)];
}

function getCopilotResponse(
  question: string,
  players: Player[],
  settings: EventSettings,
  warnings: string[]
): string {
  const lower = question.toLowerCase();

  if (!question.trim()) {
    return "Ask me about fairness, court usage, player dropouts, or schedule risks.";
  }

  if (lower.includes("fair")) {
    return [
      "To make this schedule fairer:",
      players.length % 2 !== 0
        ? "- Add one more player or create a rotating bye so no player sits too often."
        : "- Player count is even, so no bye is needed.",
      settings.courts < Math.ceil(players.length / 2)
        ? "- Add more courts or split each round into time waves."
        : "- Court count looks reasonable.",
      "- Track rest time between matches if this becomes a longer event.",
    ].join("\n");
  }

  if (lower.includes("drop")) {
    return [
      "If one player drops out:",
      "- Remove the player from the roster.",
      "- Regenerate the schedule.",
      "- If player count becomes odd, expect one bye per round.",
      "- Notify affected players whose matchups changed.",
    ].join("\n");
  }

  if (lower.includes("warning") || lower.includes("issue")) {
    return warnings.length
      ? `Current issues:\n${warnings.map((w) => `- ${w}`).join("\n")}`
      : "No major operational issues detected.";
  }

  return [
    "Suggested ops checklist:",
    "- Confirm player count.",
    "- Confirm number of courts.",
    "- Generate schedule.",
    "- Review warnings.",
    "- Share round assignments with players.",
  ].join("\n");
}

export default function TourneyCopilot() {
  const [settings, setSettings] = useState<EventSettings>({
    name: "Saturday Pickleball Round Robin",
    courts: 2,
    gamesPerMatch: 1,
  });

  const [players, setPlayers] = useState<Player[]>([
    { id: uid(), name: "Alex" },
    { id: uid(), name: "Sam" },
    { id: uid(), name: "Taylor" },
    { id: uid(), name: "Jordan" },
    { id: uid(), name: "Casey" },
  ]);

  const [playerName, setPlayerName] = useState("");
  const [question, setQuestion] = useState("");
  const [copilotAnswer, setCopilotAnswer] = useState("");

  const schedule = useMemo(
    () => generateRoundRobin(players, settings.courts),
    [players, settings.courts]
  );

  const warnings = useMemo(
    () => getWarnings(players, settings, schedule),
    [players, settings, schedule]
  );

  const addPlayer = () => {
    const name = playerName.trim();
    if (!name) return;

    setPlayers((prev) => [...prev, { id: uid(), name }]);
    setPlayerName("");
  };

  const removePlayer = (id: string) => {
    setPlayers((prev) => prev.filter((player) => player.id !== id));
  };

  const askCopilot = () => {
    setCopilotAnswer(getCopilotResponse(question, players, settings, warnings));
  };

  const rounds = schedule.reduce<Record<number, Match[]>>((acc, match) => {
    acc[match.round] ??= [];
    acc[match.round].push(match);
    return acc;
  }, {});

  return (
    <main className={styles.page}>
      <section className={styles.panel}>
        <h1>Tourney Ops Copilot</h1>

        <label>
          Event name
          <input
            value={settings.name}
            onChange={(e) =>
              setSettings((prev) => ({ ...prev, name: e.target.value }))
            }
          />
        </label>

        <label>
          Courts
          <input
            type="number"
            min={1}
            value={settings.courts}
            onChange={(e) =>
              setSettings((prev) => ({
                ...prev,
                courts: Number(e.target.value),
              }))
            }
          />
        </label>

        <label>
          Games per match
          <input
            type="number"
            min={1}
            value={settings.gamesPerMatch}
            onChange={(e) =>
              setSettings((prev) => ({
                ...prev,
                gamesPerMatch: Number(e.target.value),
              }))
            }
          />
        </label>
      </section>

      <section className={styles.panel}>
        <h2>Players</h2>

        <div className={styles.row}>
          <input
            placeholder="Player name"
            value={playerName}
            onChange={(e) => setPlayerName(e.target.value)}
            onKeyDown={(e) => {
              if (e.key === "Enter") addPlayer();
            }}
          />
          <button onClick={addPlayer}>Add</button>
        </div>

        <ul>
          {players.map((player) => (
            <li key={player.id} className={styles.player}>
              {player.name}
              <button onClick={() => removePlayer(player.id)}>Remove</button>
            </li>
          ))}
        </ul>
      </section>

      <section className={styles.panel}>
        <h2>Warnings</h2>

        {warnings.length === 0 ? (
          <p>No operational issues detected.</p>
        ) : (
          <ul className={styles.warningList}>
            {warnings.map((warning) => (
              <li key={warning}>{warning}</li>
            ))}
          </ul>
        )}
      </section>

      <section className={styles.panel}>
        <h2>Schedule</h2>

        {Object.entries(rounds).map(([round, matches]) => (
          <div key={round} className={styles.round}>
            <h3>Round {round}</h3>

            {matches.map((match) => (
              <div key={match.id} className={styles.match}>
                <span>Court {match.court}</span>
                <strong>
                  {match.playerA?.name ?? "Bye"} vs{" "}
                  {match.playerB?.name ?? "Bye"}
                </strong>
              </div>
            ))}
          </div>
        ))}
      </section>

      <section className={styles.panel}>
        <h2>AI Copilot</h2>

        <textarea
          placeholder="Ask: How can I make this schedule fairer?"
          value={question}
          onChange={(e) => setQuestion(e.target.value)}
        />

        <button onClick={askCopilot}>Ask Copilot</button>

        {copilotAnswer && <pre className={styles.answer}>{copilotAnswer}</pre>}
      </section>
    </main>
  );
}
```
